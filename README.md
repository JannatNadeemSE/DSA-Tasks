# DSA Task 1 — Java Operations

This folder contains three menu-driven Java programs:

1. `ArrayOperations.java` — add, insert, fill, delete, display, search, get/update by index, and size.
2. `StackOperations.java` — push, pop, display, size, isEmpty, and isFull.
3. `QueueOperations.java` — enqueue, dequeue, display, size, isEmpty, and isFull.

## How to run

Compile and run one program at a time:

```bash
javac ArrayOperations.java
java ArrayOperations
```

Replace `ArrayOperations` with `StackOperations` or `QueueOperations` to run another program.

The programs use Java Scanner input and if/else menu logic.
